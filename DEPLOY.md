# Публикация сайта

Сервер арендовать не нужно: сайт статический, его бесплатно хостит **GitHub Pages**. PDF пересобираются автоматически при каждом `git push` (`.github/workflows/deploy.yml`).

## 1. GitHub-репозиторий
1. Зарегистрироваться на github.com (если ещё нет аккаунта).
2. Создать репозиторий: **New repository** → имя, например `portfolio`, тип **Public**. На бесплатном тарифе Pages работает только с публичными репозиториями.
3. Отправить в него проект:
   ```bash
   cd C:\Users\Neonner\Desktop\Resume\GameDev
   git init -b main
   git add .
   git commit -m "Сайт-визитка"
   git remote add origin https://github.com/<логин>/portfolio.git
   git push -u origin main
   ```
   Файл `информация_обо_мне.txt` в `.gitignore` и в репозиторий не попадёт.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
5. Вкладка **Actions**: дождаться зелёной галочки у «Deploy site». Сайт откроется по адресу `https://<логин>.github.io/portfolio/`.

## 2. Домен
1. Выбрать имя, например `boldyrev.dev`, `boldyrev.pro` или `yboldyrev.ru`.
2. Купить домен у регистратора. Для `.ru` подойдут REG.RU или RU-CENTER (nic.ru), для них нужна верификация паспортом. Для `.com`/`.dev`/`.pro` можно взять тех же или зарубежного регистратора. Цены: `.ru` — обычно несколько сотен ₽/год, международные зоны дороже. Сравните цену **продления**, а не только первого года.
3. Сначала подтвердить домен в GitHub, чтобы его не смог привязать никто другой: **аватар → Settings → Pages → Add a domain**. GitHub выдаст TXT-запись — добавить её в DNS у регистратора и нажать **Verify**.
4. В панели регистратора (раздел «DNS-записи») добавить:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `<логин>.github.io.` |

5. В репозитории: **Settings → Pages → Custom domain** → ввести домен → **Save**. Когда проверка пройдёт (от нескольких минут до суток), включить **Enforce HTTPS**.
6. В `data/content.js` записать `shared.contacts.site = 'ваш-домен'`, сделать `git push`. Адрес сайта появится в PDF.

## 3. Почта на домене (по желанию)
- Самый простой вариант — переадресация `me@домен → ваш личный ящик`. Многие регистраторы предоставляют её бесплатно.
- Полноценный ящик — через Яндекс 360 для бизнеса или VK WorkSpace (тарифы проверьте на момент подключения). Сервис выдаст MX- и TXT-записи, их нужно добавить в DNS.
- После подключения указать адрес в `shared.contacts.email`.

## Обновление контента
1. Отредактировать `data/content.js` (и/или заменить скриншоты в `assets/img/projects/…`).
2. Проверить локально: открыть `index.html` в браузере; при желании пересобрать PDF командой `npm run pdf`.
3. Выполнить `git add . && git commit -m "…" && git push` — сайт и PDF обновятся автоматически.
